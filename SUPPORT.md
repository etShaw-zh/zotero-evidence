# Support

## Public support

Use [GitHub Issues](https://github.com/etShaw-zh/zotero-evidence/issues) for:

- questions about installing, configuring, or using Zotero Evidence;
- reproducible bug reports; and
- feature requests related to research workflows.

Search existing issues before opening a new one and use the appropriate issue
form when available. Include the Zotero Evidence version, Zotero version,
operating system, reproduction steps, and a minimal sanitized log when relevant.

## Sensitive reports

For security vulnerabilities, privacy concerns, or other information that
should not be public, email `et_shaw@126.com`.

Never post API keys, credentials, copyrighted PDFs, personally identifiable
information, confidential research data, or unredacted logs in a public issue.
Remove or replace sensitive values while preserving enough context to reproduce
the problem.

This project is maintained on a best-effort basis. The support channels do not
guarantee a response time or compatibility outside the versions documented in
the repository.
